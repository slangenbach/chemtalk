# Chemtalk

A case study about talking with AI agents in constrained industrial environments.

## Prerequisites

- [Quarto][1]
- Your favorite agent harness, e.g. [OpenCode][2]
- [OpenRouter][3] account

## Usage

Instruct the agent to read the [case study](case_study.md), consider the [context](context.md), draft or refine the [presentation](presentation.qmd) and implement the [prototype](prototype.md).


[1]: https://quarto.org/
[2]: https://opencode.ai/
[3]: https://openrouter.ai/
